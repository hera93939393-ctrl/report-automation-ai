■ 계획(안) 자동 작성 도구 — 사용법

[무엇을 하는 도구인가]
- 매번 새로 만들던 서식·도형·표를 다시 만들지 않습니다.
- 미리 만들어 둔 서식 뼈대(계획안_서식.hwp) 위에, 내용(텍스트)만 채워서
  완성된 한글파일을 자동으로 만들어 줍니다.

[사용 방법]
1. '계획안_작성도구.bat' 을 더블클릭합니다.
2. 뜨는 창의 빈칸에 내용만 입력합니다. (서식은 신경 쓸 필요 없음)
3. [한글파일 만들기] 버튼을 누르고 저장 위치를 고릅니다.
4. 완성된 계획(안).hwp 가 만들어지고, 원하면 바로 한글로 열립니다.

[폴더 안 파일 설명]
- 계획안_작성도구.bat : 실행 파일 (이것만 더블클릭하면 됩니다)
- 계획안_서식.hwp     : 서식 뼈대 (자동 생성됨 / 함부로 지우지 마세요)
- report_tool.py      : 입력 창 프로그램
- fill_core.py        : 내용 채우기 엔진
- make_template.py    : 서식 뼈대를 다시 만들 때 쓰는 프로그램

[지금 되는 것 / 다음에 추가할 것]
- (됨) 제목, 추진목적, 일시·방법·대상, 내용 항목, 세부일정 설명 자동 입력
- (다음) 세부일정 '표' 내용 자동 채우기
- (다음) 핵심만 입력하면 AI가 문장을 자동 작성

[주의]
- 한글(한컴오피스)이 설치돼 있어야 동작합니다.
- 서식 뼈대를 바꾸고 싶으면(항목 추가/삭제 등) 알려주세요. 같이 수정하면 됩니다.
