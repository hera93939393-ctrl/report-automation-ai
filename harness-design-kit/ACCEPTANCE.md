## 시나리오별 실제 증거 형식

각 U 시나리오의 `실제 증거`에는 가능한 경우 다음을 남긴다.

- 실행 날짜와 코드 버전
- 사용한 민감하지 않은 fixture 식별자
- 한글 문서 수치의 문맥과 위치
- 엑셀 파일의 시트·셀·원본 값
- 기대한 색상과 실제 색상
- 진행 이벤트 순서와 종료 상태
- 오류·미확정·확인 필요 항목
- 재검증이면 변경 전후 색상과 사용자 지정 색상 보존 여부

문서 원문 전체, 엑셀 전체 데이터, API 키와 개인정보는 증거에 포함하지 않는다.

A09는 이전 세션 자동 복원을 지원하지 않으므로 미지원 사실과 D07을 실제 증거에 기록한다. A10은 D08에서 vLLM 비교를 선택했으므로 민감하지 않은 fixture로 실행하고, 연결 실패 시 원인과 미완료 범위를 기록한다. A03의 테스트 성공만으로 코드의 모든 동작이 옳다고 주장하지 않는다.
