# 레시피: 회의결과 반영

첨부한 회의결과·메모 내용을 지금 문서의 특정 구간에 반영하는 업무.
이 파일은 사용자가 직접 읽고 고칠 수 있다 — 단계·지침을 업무 방식에 맞게 수정하세요.

## 트리거
회의결과 반영, 회의 내용 반영, 반영해서 고쳐, 내용 반영해서, 첨부 반영

## 단계
1. 첨부된 회의결과를 읽는다
2. 커서가 있는 구간(또는 지시한 구간)의 현재 본문을 읽는다
3. 회의결과 내용을 반영해 그 구간 본문을 고쳐 쓴다
4. 무엇을 어떻게 바꿨는지 근거(첨부의 해당 부분)와 함께 답한다

## 지침
- 회의결과에 없는 결정을 지어내지 않는다
- 기존 본문에서 바뀌지 않은 부분은 그대로 보존한다
- 숫자·날짜는 첨부 원문과 글자까지 똑같이 옮긴다
- 개조식 문체('-함', '-음' 종결)를 유지한다
